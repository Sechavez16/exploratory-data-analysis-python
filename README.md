# Análisis Exploratorio de Datos con Python

## Descripción del proyecto

Este repositorio reúne ejercicios prácticos de análisis exploratorio de datos (Exploratory Data Analysis, EDA) desarrollados con Python y Jupyter Notebook.

El objetivo es explorar conjuntos de datos, comprender su estructura, identificar posibles problemas de calidad y reconocer patrones que permitan interpretar la información de manera fundamentada.

Se incluyen ejercicios de análisis de datos y un estudio exploratorio de información musical relacionada con Spotify.

## Objetivos

- Explorar conjuntos de datos e identificar sus características principales.
- Examinar columnas, tipos de datos y valores faltantes.
- Aplicar técnicas de análisis exploratorio.
- Comprender la distribución y el comportamiento de las variables.
- Identificar patrones y relaciones relevantes.
- Desarrollar habilidades de análisis e interpretación de datos.

## Proyectos incluidos

### 1. Análisis de datos

**Archivo:** `Análisis_datos.ipynb`

Notebook orientado a la exploración y comprensión de un conjunto de datos mediante Python.

Se utiliza como espacio de práctica para examinar información, revisar sus características y desarrollar un flujo inicial de análisis.

### 2. Spotify Science: análisis exploratorio de datos musicales

**Archivo:** `Spotify Science.ipynb`

Estudio exploratorio de datos relacionados con canciones de Spotify.

El notebook permite examinar la estructura del conjunto de datos, revisar sus columnas, identificar valores faltantes y explorar las características disponibles para comprender mejor la información musical.

Este ejercicio sirve como base para desarrollar análisis posteriores, visualizaciones y posibles investigaciones sobre patrones musicales.

## Ejecución

1. Clona el repositorio.
2. Instala Python y Jupyter Notebook.
3. Instala las bibliotecas requeridas por cada notebook.
4. Abre el archivo `.ipynb` y ejecuta las celdas en orden.

```bash
git clone https://github.com/Sechavez16/exploratory-data-analysis-python.git
cd exploratory-data-analysis-python
pip install pandas numpy jupyter
jupyter notebook
```
